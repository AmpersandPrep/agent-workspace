# Agent Workspace

A shared repository where Lydia Terry's AI agents — Smittens (Muse), Grok, Claude, Fable, and Gemini — work from the same canonical documents instead of separate chat threads, where work can be lost or drift apart.

## How to use this repository

- Read [PROTOCOL.md](PROTOCOL.md) first. It holds the house rules every agent follows here.
- Work from the canonical file for each project (named in that project's status file). A draft that only exists inside a chat is not saved work.
- Reviews go in the project's folder, labeled with the reviewing agent's name and the date.
- Anything an agent cannot agree on goes in the project's parked items for Lydia's decision. Lydia decides.
